How can I transpose a song that is already added in a songbook?

Simply add the song again, with transposition.
In the current version, you can either add the song to song_collection and then add it to the songbook
or you can use the queue, where you add the transposition. You can also change songlist and recompile (NOT RECOMMENDED)

TRANSPOSITION USING A QUEUE:
In your format, add another string that is to be read.
Transposition must always be the last member in the format.
Then, follow that format and add the chord base after songs you'd like to transpose.
Example: Format: "%[^_]_%s -t %s"; Zafukane_fleret -t C#

TRANSPOSITION USING SONGLIST.TXT AND RECOMPILATION
NOTE that this is only safe when the recompilation is done immediately after the songlist.txt change.
You can rewrite the chord base after ';' in each entry of songlist.txt in your songbook.
Then, if you immediately recompile the songbook, you'll get the transposed versions.
