Can I edit a song in songcollection?

Yes, you can.
However, beware! Because if you re-download the song
(that is, if you try to add the song and choose 'No' after it says that it's been foun in song_collection),
the song will get overwritten is you say 'Yes' after it's been found on the web.

So unless you do 'idk' 'songname' 0 1 in this exact order, it will be kept as you intended.

WHAT YOU SHOULD NOT EDIT
You should not edit the song's .txt filename in a way that breaks its format.
The program expects name-name_author-author. If you change that, the program won't be able to read the song.
