How do I use a queue?

Go into a specific songbook's directory, go to the queue subdirectory
and open 'queue.txt'. A queue works like this:

Format: "[format]" (must contain song name, author, and optionally transposition chord)
[first]
[N formatted lines]

Where [format] represents a format according to the C standard, [first] must be
either 'author' or 'name', based off which represents the first substring in the format
and [N formatted lines] represents lines that satisfy the specified [format]
Transposition chord is always assumed to be the last of the parameters and is optional on every line

TRANSPOSITION
Besides song name and author, you can also use format to parse transposition for each song.
Transposition must be the last thing you parse from the format. If the format is "%s %s %s",
the program will always expect transposition to be at the third %s.
That way, you can, but don't have to add the transposition.
Transposition must be the base of a chord (F# from F#misus2add9).

FORMAT BASICS:
C's format (for our purposes) works like this:
%s - any sequence of characters that is followed by whitespace
%[^c] - sequence of characters followed by c (which can be any ASCII character), ignores whitespace
%*s or %*[^c] - format that you do not care about (gets read and then skipped)
\n - newline character

EXAMPLES:
Format: "%s"; string: "hello world"; parsed result: "hello" (because ' ' after "hello" is whitespace)
Format: "%*[^.].%s"; string: "hello.world1"; parsed result: "world1" (read until . and throw that away, read ., save sting)

FULL EXAMPLE:
Format: "%[^-]-%s -t %s"
name
zafukane-fleret
hlidac_krav-jaromir_nohavica -t C#

Explanation: Format says "read until '-', then read '-', then read until whitespace, then read until -t, then read until whitespace (end of line)"
"name" says that the first thing in the format will be name
therefore all lines will be in this format: name-author (-t transposition_chord) -> note that transposition chord is optional

COMMON FORMATS:
For songs taken from songlist.txt: "%[^_]_%s -t %s" (example: hlidac-krav_jaromir-nohavica -t C#)
For 'Hlídač krav - Jaromír Nohavica -t C#': "%[^-]-%[^-]-t %s"
For 'zafukane_fleret\Zafúkané\Fleret;F#': "%[^_]_%[^\]\%*[^;];%s"
