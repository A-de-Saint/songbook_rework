Unfirom song format:
- Divide song into sections
- Best find a source where I get in-line chords (type 2)
    - Because type2 => type1 works, but type1 => type2 is risky
- Sources (priority odered):
    1. https://akordy.kytary.cz/ (type 1)
        - has chords throughout the entire song
        - easily convertible to type2
        - naming is weird
            - {url}/song/{songname}
            - for different authors it's 
                - {url}/song/{songname}-2
                - or 3, 4, so on...
    2. https://pisnicky-akordy.cz/ (type 1)
        - better naming conventions
            - {url}/{author}/{songname}
            - but jarek-nohavica instead of jaromir-nohavica, lidove, taborove, some weird shit...
        - easily obtainable chords
            - but no support for type2
            - often not throughout the entire song
    3. https://www.brnkni.cz/ (type 2)
        -impeccable naming conventions
            - {url}/{author[0]}/{author}/{songname}
        - type 2, well convertible, but unstable
            -sometimes mid-syllable


songlist.txt
    - save songs by their filename in song_collection
    - format:
        "%s_%s", song->name_ascii, song->author_ascii

saving a song
    - options:
        1. save only to song_collection
        2. save to song_collection and turn it into given format
        - easy solution - just return song (in parameters), and if 1., dtor it rightaway
    - workflow:
        - first of all, the implementation should be as follows:
            - user writes song name and author, which get converted to ascii only formatted text
            - if user types 'idk' as an author, it should look for all possibilities
        1. Try to find given song in song_collection
            - if (!idk) -> get print -> strcmp until found or EOF
            - if (idk) -> decode each -> strcmp on name -> if match, ask user
        2. (!found) download song (akordy-kytary)
            - if (!idk) -> download -> parse author -> negative -> not found (tell user to try again with 'idk')
            - if (idk) -> download -> parse author -> ask user -> negative -> do it again, with i+1

song formatting on akordy-kytary
    - div id=sheet-content
        - more divs
            - set of div class=scs-section
            - each is class=scs-section data-type={intro || verse || chorus || interlude || ending}
                - within each set of divs representing lines
                    - lyrics directly within
                    - chords always where they should be (mid-syllables)
                        - chords like this:
                        - div class=scs-chord
                            - span class=scs-chk (main chord part)
                            - span class=scs-chv (minor or something) (optional)
                -example:
                    <div>
                    <div class="scs-chord"><span class="scs-chk">C</span></div>Z rozmláce<div class="scs-chord"><span class="scs-chk">A</span><span class="scs-chv">m</span></div>nýho kostela
                    </div>

song formatting (my style)
    - first two lines will contain name and author
    - state-style 
        - based on my SongState enum
        - every SongPart will look like this:
            - \num\

            - where num is enum to int and lines are lines
    - lines saved like this:
        [C]Z rozmláce[Ami]nýho kostela
